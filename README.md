# Умный супермаркет

Интерактивный локальный урок по основам программирования для детей: линейный алгоритм, ветвление и цикл. Главный герой — оригинальный техно-помощник Робик в едином книжно-анимационном стиле.

## Запуск

Откройте `index.html` двойным щелчком. Интернет и установка программ не требуются.

Для публикации загрузите содержимое папки в GitHub и включите GitHub Pages в настройках репозитория.

## Сценарий на 20 минут

- 2 минуты — приветствие и цель миссии.
- 5 минут — объяснение и двигательная разминка.
- 4 минуты — игра «Собери покупку».
- 3 минуты — игра «Развилка решений» с двумя ветвями истории.
- 3 минуты — игра «Три дня покупок» с повторяющимся маршрутом.
- 3 минуты — проверка и рефлексия.

Ответы рефлексии сохраняются только в браузере на текущем устройстве (`localStorage`).

Звуковые эффекты создаются прямо в браузере и работают без внешних файлов. Кнопка «Звук» позволяет их отключить.

Пятая вкладка открывает внешнее бонусное упражнение [Compute It](https://compute-it.toxicode.fr/) в новой вкладке. После возвращения ученик подтверждает выполнение и получает пять бонусных звёзд. Для внешнего упражнения нужен интернет.
